Pipeline Architecture

Single-File Code Layout

The entire pipeline is housed within one file: src/er_pipeline.py. The code execution sequentially follows the flow of data.

textnorm & prep
Parsing and name/address normalization (transliteration, accents, OCR digits, aliases, websites, legal forms).
retrieve
Numba-optimized multi-channel inverted index for high-recall blocking.
features & stage0
Generation of pair features, cross-fitted token risk, and the stage-0 re-ranker model.
train_model
Stage-1 and Stage-2 LightGBM model training using cross-fitted predictions.
france_* methods
Unsupervised handling for France leveraging self-training and explicit noise-word rules.
predict & decide
Many-to-one assignments guided by the per-entity expected-F0.5 rule. Output writing to TSV.

Filtering Candidate Sets

While Phase-0 generation produces up to 43.4 million test pairs, our cand_filter step ensures computational efficiency for inference. Only pairs scoring above a probability threshold of 0.0005 are forwarded to the final matchers, narrowing the candidate pool down to 8.3M test pairs (approximately 4.8 candidates per Source 1 entity).

Business Entity Resolution Solution

A high-performance classical ML pipeline developed by Tensor Titans for the ML Challenge 2026. Achieved an impressive 0.987221 F-score without external data or APIs.

Explore Methodology

Executive Summary

Our solution links each Source 2/3 record to at most one Source 1 business, or to none. A joint name and address inverted index retrieves 98.9% of the true links. We utilized a cross-fitted LightGBM matcher with 82 pair features to score candidates, followed by a stage-2 model that adds 9 competition-context features.

🎯 Generator Targeting

By measuring how the data was generated, we identified legal-form conflicts as the signature of "sibling" businesses, leading to our largest performance gains.

⚡ Joint Retrieval

An inverted-index retriever written in numba uses joint multi-channel scoring, outperforming fixed capped per-Source-1 blocks.

🧠 Unseen-Country Model

We developed a label-free diagnosis for France (which had no training labels) using a leave-one-country-out approach and a measured noise-word rule.

🚀 Classical ML Pipeline

The entire pipeline uses classical ML exclusively—string normalization, inverted indexing, and gradient boosting—requiring zero external APIs.

Results

  • Leaderboard: 0.987221 (final submission v14l)
  • F_0.5 Score (macro): 0.9888 out-of-fold over 2.2M train entities
  • Unseen-country proxy: Improved from 0.868 to 0.946 using leave-one-country-out training and self-training on confident pseudo-labels
